# Enosh David Singh Portfolio

A portable Next.js portfolio with responsive design, live project links, subtle motion, and a command-line project updater.

## Start locally

```powershell
npm install
npm run dev
```

## Add a project without editing React

```powershell
npm run portfolio:wizard
```

## Validate, commit, and push

```powershell
npm run portfolio:push -- --message "Add project name"
```

Read `PORTFOLIO_TOOL_GUIDE.md` for the complete beginner-friendly GitHub and Vercel workflow.
