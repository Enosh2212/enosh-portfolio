# The Unfolding Archive

Enosh David Singh’s local portfolio preview. Built with Next.js App Router and TypeScript.

- `npm ci` installs dependencies.
- `npm run dev -- --port 3107` starts the local preview.
- `npm run lint`, `npm run typecheck` and `npm run build` verify the project.
- Edit `content/work.ts` to update case studies and experiments.
- The archive opens on tap or keyboard activation. Animated cover and paper leaves reveal the site. Skip, direct section links and reduced motion are supported. Internal routes use a paper transition.
- Project cover illustrations represent the work. The Tideset case study includes an actual app screenshot.
